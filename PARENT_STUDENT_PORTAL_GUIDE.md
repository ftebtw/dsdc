# DSDC Parent and Student Portal Guide

This guide is for parents and students.

It is written in very simple English and Chinese.

Use this guide for:

1. Creating an account
2. Verifying your email
3. Linking parent and student accounts
4. Registering for classes
5. Paying for classes

Main registration page:

`https://dsdc.ca/register`

Main portal login page:

`https://dsdc.ca/portal/login`

---

## English Guide

### 1. Which account should I make?

Make a `Parent` account if:

1. A parent or guardian will manage classes or payments
2. You want to link your child to your portal

Make a `Student` account if:

1. The student will log in directly
2. The student wants to see classes, homework, and attendance

Many families use both:

1. Parent makes a parent account
2. Student makes a student account
3. Then they link the two accounts together

### 2. Before you start

Please prepare:

1. An email address you can open right away
2. A password you can remember
3. A phone or computer
4. A payment method if you will register for classes now

### 3. How to create a parent account

1. Open `https://dsdc.ca/register`
2. Choose `I'm a Parent`
3. Enter:
   first name
   last name
   email
   password
   phone number if you want
4. Submit the form

Important:

The parent signup form does not link your child yet.

You will link the student account after logging in.

### 4. How to create a student account

1. Open `https://dsdc.ca/register`
2. Choose `I'm a Student`
3. Enter:
   first name
   last name
   email
   password
4. Submit the form

### 5. Check your email and verify your account

After registering, DSDC sends a verification email.

Steps:

1. Open your email inbox
2. Find the DSDC verification email
3. Click the verification link in the email
4. Return to DSDC and continue

If you do not see the email:

1. Check Spam or Junk
2. Search your inbox for `DSDC`
3. Use the resend option if needed

What usually happens next:

1. Students can usually go straight to enrollment after verification
2. Parents usually go to the portal first, link a student account, and then enroll

### 6. How to choose classes and pay

The next step depends on the account type.

If you are a student:

1. Verify your email
2. Open your student portal
3. Go to enrollment
4. Choose classes
5. Pay

If you are a parent:

1. Verify your email
2. Log in to the parent portal
3. Link your student account first
4. Then choose classes for that student
5. Pay

Usual steps:

1. Review the available classes
2. Select the class or classes you want
3. Continue to payment
4. Choose a payment method
5. Finish payment

Common payment choices:

1. `Card`
   This is the easiest option for most families.
2. `e-Transfer`
   Use this if DSDC told you to pay by e-Transfer.
3. `Already Paid`
   Only use this if DSDC already told you your payment was handled.

### 7. How parents link to students

After the parent account and student account both exist, link them together.

There are 2 simple ways.

#### Method A: Parent links using student email

This is often the easiest method.

Steps:

1. Parent logs in to the portal
2. Parent opens the parent dashboard
3. Parent chooses the option to link a student
4. Parent enters the student's email
5. DSDC sends a 6-digit code to the student's email
6. Student checks email and gives the code to the parent
7. Parent enters the code
8. Accounts are linked

#### Method B: Parent creates an invite code

Steps:

1. Parent logs in to the portal
2. Parent creates a parent invite code
3. Parent gives the code to the student
4. Student logs in
5. Student opens the parent-link page
6. Student enters the code
7. Accounts are linked

### 8. How students link to parents

If the parent already made an invite code, the student can link from the student portal.

Steps:

1. Student logs in
2. Open the page to link a parent
3. Enter the parent invite code
4. Submit

### 9. How parents register a linked student for classes

After linking, the parent can manage the student more easily.

Parent steps:

1. Log in to the parent portal
2. Choose the correct student
3. Open the enroll or classes area
4. Choose classes for the active term
5. Pay

### 10. How students register themselves for classes

Students can also enroll themselves if allowed by the family.

Student steps:

1. Log in to the student portal
2. Open the enroll page
3. Choose active classes
4. Continue to payment
5. Finish payment

### 11. After registration, where do we find everything?

After login:

Parents can usually see:

1. Linked student account
2. Classes
3. Attendance
4. Resources
5. Report cards
6. Enrollment and payment actions

Students can usually see:

1. My Classes
2. Attendance
3. Resources
4. Homework
5. Report cards

### 12. Very simple family setup example

Example:

1. Parent creates a parent account
2. Student creates a student account
3. Both verify their email
4. Parent links student
5. Parent chooses classes
6. Parent pays
7. Student logs in later to see class materials

### 13. Common problems

#### I did not get the verification email

1. Check Spam or Junk
2. Search for `DSDC`
3. Try resending the email

#### The code does not work

1. Make sure you are using the newest code
2. Type it carefully
3. Ask for a new code if needed

#### I made only a parent account, but no student account

That is okay.

Please create the student account next, then link it to the parent account.

#### I do not know which payment option to choose

For most families, choose `Card`.

Only choose `e-Transfer` or `Already Paid` if DSDC told you to do that.

### 14. Quick version for parents

1. Make a parent account
2. Make a student account
3. Verify both emails
4. Link parent and student
5. Choose classes
6. Pay
7. Log in later to see updates

## 中文指南

### 1. 应该注册哪一种账号？

如果家长要管理课程或付款，请注册 `Parent` 账号。

如果学生要自己登录查看课程、作业和出勤，请注册 `Student` 账号。

很多家庭会两个都注册：

1. 家长注册 `Parent`
2. 学生注册 `Student`
3. 然后把两个账号绑定起来

### 2. 开始前请准备

请先准备：

1. 一个可以马上查看的邮箱
2. 一个记得住的密码
3. 手机、平板或电脑
4. 如果今天要报名，请准备付款方式

### 3. 家长账号怎么注册

1. 打开 `https://dsdc.ca/register`
2. 选择 `I'm a Parent`
3. 输入：
   名
   姓
   邮箱
   密码
   电话号码（可选）
4. 提交

请注意：

家长注册时，不会马上自动绑定学生。

需要登录后，再去绑定学生账号。

### 4. 学生账号怎么注册

1. 打开 `https://dsdc.ca/register`
2. 选择 `I'm a Student`
3. 输入：
   名
   姓
   邮箱
   密码
4. 提交

### 5. 去邮箱验证账号

注册后，DSDC 会发送验证邮件。

步骤：

1. 打开邮箱
2. 找到 DSDC 的验证邮件
3. 点击邮件里的验证链接
4. 回到 DSDC 继续下一步

如果没有看到邮件：

1. 看垃圾邮件或广告邮件
2. 搜索 `DSDC`
3. 如果需要，重新发送验证邮件

通常下一步会是：

1. 学生验证后，一般可以直接去报名课程
2. 家长验证后，一般先登录门户，绑定学生，再报名

### 6. 怎么选课和付款

下一步会根据账号类型不同而不同。

如果你是学生：

1. 验证邮箱
2. 打开学生门户
3. 进入报名页面
4. 选课
5. 付款

如果你是家长：

1. 验证邮箱
2. 登录家长门户
3. 先绑定学生账号
4. 再为学生选课
5. 付款

一般流程：

1. 查看可报名课程
2. 选择想要的课程
3. 继续到付款页面
4. 选择付款方式
5. 完成付款

常见付款方式：

1. `Card`
   大多数家庭选这个，最简单。
2. `e-Transfer`
   如果 DSDC 告诉你用电子转账，就选这个。
3. `Already Paid`
   只有 DSDC 已经告诉你“已经付过款”时才选这个。

### 7. 家长怎么绑定学生

家长账号和学生账号都建立好以后，就可以绑定。

有两种简单方法。

#### 方法 A：家长用学生邮箱绑定

这个方法通常最简单。

步骤：

1. 家长登录门户
2. 打开家长首页
3. 选择绑定学生
4. 输入学生邮箱
5. 系统会发送 6 位数字验证码到学生邮箱
6. 学生查看邮箱，把验证码告诉家长
7. 家长输入验证码
8. 绑定完成

#### 方法 B：家长先生成邀请码

步骤：

1. 家长登录门户
2. 生成家长邀请码
3. 把邀请码发给学生
4. 学生登录
5. 学生打开绑定家长页面
6. 输入邀请码
7. 绑定完成

### 8. 学生怎么绑定家长

如果家长已经有邀请码，学生可以在自己的门户里绑定。

步骤：

1. 学生登录
2. 打开绑定家长页面
3. 输入家长邀请码
4. 提交

### 9. 家长怎么帮孩子报名课程

绑定完成后，家长会更容易管理学生。

步骤：

1. 家长登录门户
2. 选择正确的学生
3. 打开报名或课程页面
4. 选择当前学期课程
5. 付款

### 10. 学生怎么自己报名课程

如果家庭同意，学生也可以自己报名。

步骤：

1. 学生登录门户
2. 打开报名页面
3. 选择当前学期课程
4. 继续付款
5. 完成付款

### 11. 登录后可以在哪里看信息？

家长通常可以看到：

1. 已绑定的学生
2. 课程
3. 出勤
4. 资源
5. 评语卡
6. 报名和付款

学生通常可以看到：

1. My Classes
2. Attendance
3. Resources
4. Homework
5. Report Cards

### 12. 一个最简单的家庭例子

例子：

1. 家长先注册家长账号
2. 学生再注册学生账号
3. 两边都去邮箱验证
4. 家长绑定学生
5. 家长选课
6. 家长付款
7. 以后学生登录查看课程资料

### 13. 常见问题

#### 没收到验证邮件

1. 先看垃圾邮件
2. 搜索 `DSDC`
3. 重新发送验证邮件

#### 验证码不能用

1. 确认用的是最新的验证码
2. 小心检查每个数字或字母
3. 如果需要，重新获取一个新码

#### 我只注册了家长账号，还没有学生账号

没关系。

下一步先帮学生注册学生账号，然后再绑定。

#### 我不知道该选哪种付款方式

大多数家庭直接选 `Card` 就可以。

只有 DSDC 特别说明时，才选择 `e-Transfer` 或 `Already Paid`。

### 14. 给家长看的超简单版本

1. 注册家长账号
2. 注册学生账号
3. 两边都验证邮箱
4. 绑定家长和学生
5. 选课
6. 付款
7. 以后登录查看更新
